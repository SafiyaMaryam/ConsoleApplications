**Java JDBC Mini Projects** 🚀

A collection of 4 console-based Java applications demonstrating JDBC for database operations (CRUD, queries, validation).

**📋 Projects**
**Project	Description**
1.Student Management	Add/update/delete student records with search
2.Inventory Tracker	Manage stock levels and generate reports
3.Employee Database	HR system with employee data handling
4.Library System	Book lending, returns, and overdue tracking


**🛠 Tech Stack:**
Java 8+

JDBC

MySQL (configurable for PostgreSQL)

Maven (or Gradle)

🚀** Quick Start**
Clone the repo

bash
git clone https://github.com/yourusername/java-jdbc-projects.git
cd java-jdbc-projects
Setup Database

Install MySQL

Run sql/setup.sql in each project folder

Update db.properties with your credentials

**Run a project**

bash
cd student-management
mvn clean compile exec:java -Dexec.mainClass="StudentApp"
📁 Folder Structure
text
java-jdbc-projects/
├── student-management/
├── inventory-tracker/
├── employee-database/
├── library-system/

└── README.md
